# Ditto Group Mode Build Plan

This prototype is intentionally built in milestones.

Each milestone should be fully working before beginning the next.

Never skip milestones.

---

# Milestone 1

Project Foundation

Goal:

Create a polished mobile-first experience.

Deliverables:

- phone frame
- iMessage interface
- participant switching
- landing page
- hidden demo controls
- responsive layout

No AI.

No matching.

No backend.

Hardcoded demo data only.

Definition of Done:

A founder can switch between four fictional users and view separate conversations.

---

# Milestone 2

Static Product Demo

Goal:

Implement the complete experience using fictional data.

Deliverables:

- invitation
- group reveal
- pre-date task
- reminders
- live tasks
- Nightly Signal
- midnight reveal

Everything should function as a predetermined story.

Definition of Done:

The entire prototype can be demonstrated from beginning to end.

---

# Milestone 3

Interactive Simulation

Goal:

Replace static screens with interactions.

Deliverables:

- selectable choices
- task progression
- participant-specific state
- demo control panel
- multiple endings

Definition of Done:

Presenter controls the complete experience.

---

# Milestone 4

Matching Visualization

Goal:

Show how Ditto creates groups.

Deliverables:

- fictional applications
- chemistry visualization
- compatibility explanation
- group optimization

Definition of Done:

Founders understand why these people became a group.

---

# Milestone 5

AI Layer

Goal:

Replace hardcoded content with AI-generated content where appropriate.

Potential areas:

- date plans
- messages
- chemistry explanations
- personalized tasks

Definition of Done:

Prototype feels dynamic while preserving the same UX.

---

# General Rules

Never redesign completed milestones unless requested.

Always preserve previous functionality.

Always explain changes in plain English.

Test every milestone before moving on.

Fix bugs before adding new features.
