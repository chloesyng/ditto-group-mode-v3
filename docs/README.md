# Ditto Group Mode Prototype

## Overview

This project is an independent speculative prototype exploring a potential Group Mode experience for Ditto AI.

It is not affiliated with Ditto and does not use Ditto's internal code, APIs, infrastructure, or user data.

The purpose of this prototype is to explore how AI can orchestrate highly engaging group dating experiences that create stronger chemistry than traditional one-on-one blind dates.

This prototype is built for demonstration and product exploration only using fictional users and simulated data.

---

## Vision

Current dating products focus on matching.

This project explores what happens after matching.

Instead of sending two strangers on a date and hoping chemistry naturally develops, Ditto Group Mode actively orchestrates the experience throughout the date.

Inspired by dating shows such as:

- Single's Inferno
- Transit Love (EXchange)
- Heart Signal
- Love Island

Ditto continuously creates opportunities for:

- bonding
- emotional tension
- chemistry
- playful competition
- butterfly moments
- memorable shared experiences

through personalized activities and private iMessage conversations.

---

## Core Experience

The prototype demonstrates:

- AI-generated group formation
- private participant conversations
- personalized group date planning
- live task orchestration
- dynamic pair rotations
- Nightly Signal
- midnight mutual match reveal

The primary experience takes place inside a full-phone mobile interface that simulates Ditto texting each participant individually.

---

## Important

This prototype intentionally simulates many backend systems.

Matching logic, scheduling, AI reasoning, and message generation are represented using fictional data for demonstration purposes.

The objective is to demonstrate product vision and interaction design rather than production infrastructure.
