# Ditto Group Mode — Design Principles

## Purpose

This is not a dashboard.

This is not a SaaS product.

This is not an AI tool.

It should feel like a premium consumer product that someone discovers on Product Hunt, Apple Design Awards, or Awwwards.

The founder should feel:

"I want this to exist."

Not:

"I understand how it works."

Emotion comes before explanation.

---

# Overall Inspiration

Primary references:

- Ditto
- Apple
- Arc Browser
- Notion Calendar
- Linear
- Airbnb editorial pages
- Modern dating apps

Avoid inspiration from:

- Generic SaaS landing pages
- AI dashboard templates
- Bootstrap cards
- Material Design admin panels
- Startup hero sections

---

# Design Personality

Keywords:

Warm

Human

Editorial

Confident

Playful

Minimal

Thoughtful

Premium

Natural

Curious

---

# Photography

Whenever possible:

Use photography.

Do NOT use gradients as the primary visual.

Avoid fake illustrations.

Avoid abstract AI artwork.

Photography should feel:

golden hour

film-like

slightly imperfect

real people

real environments

warm skin tones

natural light

---

# Layout

Avoid putting everything in the center.

Instead:

large photography

asymmetrical layouts

editorial spacing

breathing room

sections that feel like magazine spreads

Scrolling should feel cinematic.

---

# Typography

Typography is the hero.

Large headlines.

Short paragraphs.

Lots of whitespace.

Never feel crowded.

The user should understand hierarchy immediately.

---

# Motion

Motion should feel invisible.

Not flashy.

Animations should communicate intent.

Think:

Apple

Arc

Linear

Not:

PowerPoint

Keynote

Dribbble animation showcase

---

# Color

Mostly neutral.

Let photography provide color.

Accent color should only appear:

buttons

small highlights

notifications

Never paint entire sections pink or purple.

---

# Founder Mode

Founder Mode is a documentary.

The founder is watching Ditto think.

It should feel:

calm

confident

intelligent

premium

Never overwhelming.

Never expose unnecessary data.

---

# Participant Mode

Participant Mode should disappear.

It should genuinely feel like:

Messages.app

Not:

an imitation.

Bubble timing.

Typing indicators.

Spacing.

Everything should feel authentic.

---

# Cards

Avoid obvious rounded SaaS cards everywhere.

Use framing only when necessary.

Sometimes content should simply exist on the page.

---

# Copy

Short.

Human.

Natural.

Never explain too much.

Trust the visuals.

---

# White Space

When unsure:

remove something.

Not add something.

---

# Visual Goal

Every screenshot should be believable as an official Ditto product reveal.

If someone saw a screenshot on X or Product Hunt, they should assume it came from the Ditto design team.
